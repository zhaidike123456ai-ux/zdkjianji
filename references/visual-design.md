# 视觉设计与语义动效

## 默认视觉语言

- 画布：9:16，浅蓝渐变信息板与深色人物强调页交替。
- 卡片：白底、轻描边、柔和阴影、清晰圆角。
- 强调色：蓝色用于结构，黄色用于字幕关键词，红色只用于风险或错误。
- 人物窗：统一圆角和安全边距，避免章节间无理由改变尺寸。

## 语义映射

| 文案类型 | 推荐画面 |
|---|---|
| 步骤、流程 | 编号卡片、进度条、依次点亮 |
| 因果关系 | 左到右链路、箭头、状态变化 |
| 方向、运动 | 气流线、路径、轻量粒子 |
| 风险、警告 | 对比卡、风险色、错误状态 |
| 防护、完成 | 勾选、护盾、逐项激活 |
| 总结 | 三项清单、回收前文颜色和图标 |

## 转场

- 常规章节切换使用 8–12 帧。
- 人物全屏与小窗切换优先使用 match-scale、遮罩或同方向位移。
- 浅色页与深色页之间加入色彩桥接，避免无承接硬切。
- 字幕在转场完成后再建立最高对比，防止“空页 + 浮字”。

## 节奏

- 卡片入场后仍应保留与语义有关的微动效，但避免所有组件持续浮动。
- 相同布局连续使用两节以上时，至少变化信息结构、人物比例或主动画机制。
- 总结页至少停留到观众能扫完全部条目，通常不少于 2.5 秒。

## 资产复用

复制 `assets/knowledge-card/` 到 Remotion 工程后，根据内容调整主题和安全区。模板只规定结构，不固定文案、章节数或画面素材。
