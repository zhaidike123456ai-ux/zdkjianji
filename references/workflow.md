# 制作流程与产物

## 1. 建立非破坏性目录

建议结构：

```text
project/
├── media/                 # 原始文件、代理、连续剪辑母版
├── transcript/            # 原始转写与人工纠正
├── remotion-video/        # 可预览工程
├── output/
│   ├── review/            # 审查截图、报告、短测试
│   ├── final/             # 当前可交付版本
│   └── archive/           # 可恢复旧版
└── scripts/               # 本项目的确定性生成脚本
```

绝不覆盖原始素材。半成品从 `final/` 移入 `archive/`，避免误交付且保留恢复能力。

## 2. 媒体检查与代理

记录：

- 宽高、横竖屏、帧率、帧率模式和时长
- 视频/音频编码、采样率和声道
- 像素格式、色彩范围、色彩空间、传递函数和原色
- 旋转元数据与音视频时长差

代理保持原比例和恒定帧率。竖屏源通常以高度 720 或 480 生成；音频保留足够清晰度用于对口型检查。

## 3. 转写与删除决策

保留两套事实：

1. 原始逐字稿：反映实际说了什么。
2. 终版逐字稿：反映剪掉口误和气口之后保留了什么。

删除项必须包含源时间范围、类型、理由和衔接风险。典型类型：重录残句、重复句、填充词、长停顿、吸气、咂嘴和明确口误。不要删除有语义作用的自然停顿。

## 4. 连续剪辑母版

把已确认删除区间应用到视频和音频，生成单一 CFR 文件。所有字幕、章节标记和动效时间都使用同一源到成片的映射函数。删除时间区间后：

```text
output_time(source_t) = source_t - sum(deleted_duration before source_t)
```

若源时间落在删除区间内，将它钳制到该删除区间的成片边界。

## 5. 风格设计

先制作 3–6 个风格帧：开场、信息板、重点章节、总结和结尾。确认颜色、字体、人物窗比例、字幕位置、卡片阴影和转场语言后，再铺满全片。

需要外部组件时优先查官方 Remotion 文档，再查维护活跃、许可证明确的开源社区。记录复用组件和许可证，不复制来源不明的成品风格。

## 6. Studio 预览

默认打开代理 Composition。检查：

- 0 帧是否完整，不出现“加载一半”的空页面
- 每个章节切换前后至少 12 帧
- 页面标题、字幕和人物窗是否争抢
- 静态卡片是否有必要的语义微动效
- 源视频已有字幕和 CTA 是否被妥善处理

只有收到明确确认后，才进入完整母版渲染。

## 7. 独立视觉审查

三个审查者分别按 100 分评价：

- 卡片与信息设计：25
- 转场与剪辑衔接：20
- 视觉动效：20
- 字幕可读性：15
- 构图与风格一致性：15
- 技术完成度：5

每人给出总分、分项分、带时间码的问题、优点和五项最高优先级修改。主代理在所有独立报告完成后计算均分、中位数和共识问题；分歧项回看片段，不用投票代替证据。

## 8. 确认分辨率并输出

渲染前读取 `resolution-policy.md`。若用户没有给出明确规格，报告源素材状态并询问用户选择；同时给出推荐项，避免把技术判断全部丢给用户。

若原素材本身低于 1080P，可根据发布平台使用 1080P 设计画布，但不得声称提升了真实细节。2K 只有在源素材、矢量设计或明确发布需求受益时使用。

最终交付至少包含：

- MP4 成片
- 终版 SRT
- 终版逐字稿与时间码
- 必要时附视觉审查报告
